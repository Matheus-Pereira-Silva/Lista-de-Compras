Política de Privacidade
Lista de Compras — como seus dados são tratados neste app.
Quais dados coletamos
  • E-mail e senha, usados só para login (a senha é tratada pelo Firebase Authentication, do Google — nunca passa pelos nossos servidores nem é armazenada por nós em texto puro).
  • As listas de compras que você cria: nome da lista e os membros que participam dela.
  • Os itens dessas listas: nome do produto, quantidade, unidade, categoria e preço (quando informado).
  • Código de convite, quando você compartilha uma lista com outras pessoas.
Onde esses dados ficam
Tudo é armazenado no Firebase (Cloud Firestore e Firebase Authentication), um serviço do Google Cloud. Não mantemos servidores ou bancos de dados próprios.
Compartilhamento e publicidade
Não vendemos nem compartilhamos seus dados com terceiros para fins de publicidade. Os dados de uma lista só são visíveis para os membros dessa lista — nunca para outras pessoas de fora dela.
Como excluir seus dados
Você pode excluir sua conta e seus dados a qualquer momento, direto no app: abra "Minhas Listas", toque no ícone ⚙️ e depois em "Excluir minha conta". Se não tiver acesso ao app, veja as instruções em excluir-conta.html.
